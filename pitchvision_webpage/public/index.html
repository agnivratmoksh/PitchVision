COMPUTER VISION PROJECT

PitchVision: AI-Powered Football Match Analysis

A computer vision pipeline for detecting football players and the ball, classifying teams, estimating player positions, identifying formations, and generating basic tactical information from match images.

PROBLEM STATEMENT

Extracting structured information from football match images.

A football match image contains information about player positions, team structure, field geometry, and the spatial organization of the game.

PitchVision aims to automatically extract this information using computer vision, deep learning, machine learning, and spatial analysis.

The system begins with low-level visual detection and progressively converts the detected objects into a structured representation of the match.

01 Detect players, referees and ball
02 Classify players into teams
03 Estimate player positions
04 Identify team formations
05 Generate tactical metrics
